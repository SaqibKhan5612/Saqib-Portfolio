# React Portfolio

A polished single-page portfolio built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide icons.

## Getting Started

Install dependencies and run the local development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Customize

Edit the portfolio data in `src/App.tsx`. Keep `public/resume.pdf` for the CV download link, and add a portrait image at `public/photo.png` if you want the hero/about image to use your photo automatically.
